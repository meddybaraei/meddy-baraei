What's included

  • Compatibility check of your furnace, air handler or heat pump wiring
  • Power solution when there is no C-wire
  • Clean wall plate or trim so old paint lines are covered
  • Multi-zone homes with one thermostat per zone
  • Schedules, Eco temperatures and app sharing set up with you

How we install

  1. Check the system. We identify your equipment and existing wiring before removing the old thermostat.
  2. Solve power. If your system lacks a common wire, we add one or use the right power accessory.
  3. Install and configure. The thermostat is mounted, leveled and set for your exact system type.
  4. Test heating and cooling. We run each stage so you know the system responds correctly.
Good to know

Advice from our installs

Heat pumps. Many Northern Virginia homes use heat pumps with auxiliary heat. Correct setup keeps the expensive backup heat from running when it doesn't need to.

Zoned homes. Two- and three-story homes often have separate zones. Each zone gets its own thermostat, and all of them appear in one app.

FAQ

Nest Thermostats questions

Does a Nest thermostat work with my system?

Most forced-air and heat pump systems are compatible. We confirm before installing and tell you up front if yours needs extra parts.

What if I don't have a C-wire?

We can add one where possible or use the power accessory designed for your system.

Can you install thermostats for multiple zones?

Yes. We install one per zone and set them all up in the same app.
