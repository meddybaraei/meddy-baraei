# NovaProHome — Website V.2

Static, dependency-free redesign of novaprohome.com in the dark-and-gold style of atxautomations.com.

- `index.html` — single-page site (hero, services, why us, process, about, service areas, FAQ, contact)
- `styles.css` — all styling (colors are CSS variables at the top)
- `main.js` — mobile menu, services dropdown, scroll reveal, contact form
- `assets/meddy.png` — founder headshot

## Customize
- **Hero photo:** add your own image as `assets/hero.jpg` (wide, ~2000px). It overrides the stock photo automatically.
- **Contact form:** currently opens the visitor's email app pre-filled to meddy@novaprohome.com. To receive submissions directly, point the form at a service like Formspree or Netlify Forms.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
